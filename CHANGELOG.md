# Changelog

## 1.5.2.post2

First public release of the freezer-box fork: four demo screenshots, a step-by-step installation and usage guide, separate API/developer documentation, and GitHub/PyPI release automation. Runtime behavior and API are unchanged from 1.5.2.post1.

## 1.5.2.post1

Initial freezer-box workflow based on upstream 1.5.2: 9×9 and 10×10 layouts, atomic creation, occupancy checks, safe retries, a CSV importer, native permissions/token validation, and restored session CSRF protection.
